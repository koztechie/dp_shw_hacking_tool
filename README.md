# ⚡ DP_SHW_Hacking_Tool

Повністю автономна MLOps-система для AI-аналізу хакатонів на платформі Devpost. Інструмент автоматично збирає дані, прогнозує ймовірність перемоги (за допомогою Machine Learning), генерує інноваційні ідеї через каскадний ШІ-роутер та створює детальні технічні завдання (TechSpec).

## 🚀 Швидкий старт

### 1. Налаштування оточення
Створіть файл `.env` у корені проекту та додайте ваші ключі доступу:
```ini
GEMINI_API_KEY=ваш_ключ_gemini
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ_openrouter
SENTRY_DSN=https://ваш_dsn_від_sentry  # Опціонально, для моніторингу помилок
```

### 2. Запуск системи
Усі компоненти системи (DuckDB, FastAPI, AI Router) запускаються однією командою:
```bash
./start.sh
```
Відкрийте у браузері: **http://127.0.0.1:8000**

---

## ⚙️ Робочий процес (Workflow)

1. **Навчання (Training):** На вкладці `/training` запустіть фоновий збір даних. Скрапер автоматично збере деталі хакатонів, проекти, теги та метрики GitHub в локальну БД DuckDB.
2. **Аналіз (Analyze):** Вставте URL нового хакатону. Система обійде захист, витягне юридичні правила (Hard Constraints) та проведе стратегічний AI-аналіз.
3. **Вибір Ідеї (Ideas):** Система згенерує 3 ідеї. Кожна ідея оцінюється ML-моделлю (Random Forest / XGBoost) для визначення `%` ймовірності перемоги.
4. **Технічне завдання (TechSpec):** Для обраної ідеї генерується погодинний план розробки на 48 годин. Документ можна миттєво експортувати у форматі **Markdown (.md)**.

## 🧠 MLOps та Антикрихкість

* **Каскадний AI-Роутер:** У разі падіння API від Google (503 помилка), система миттєво та непомітно перемикається на безкоштовні моделі з OpenRouter (Llama 3.3, Qwen 2.5).
* **Self-Evolution Engine:** Після внесення результатів хакатону в історію, система аналізує свої помилки (Data Drift) і надсилає готові промпти у Sentry для самостійного оновлення коду.
* **Відмовостійка БД:** Використовується транзакційна запис у DuckDB з автоматичним бекфілом та захистом від блокувань.
